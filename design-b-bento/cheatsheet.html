Build a website with AI: all 11 steps

From a mood board to a live website in one evening. A short course by Ian Ramírez, Invest Puerto Rico.

Make a folder or note called My Website. Everything you collect goes there.

← Back to the deck

Collect

  1. Images: save 5 to 10 looks you love to one board on pinterest.com.
  2. Animations: save 1 or 2 effect links from originkit.dev and note which section each goes in.
  3. Colors: copy one 4-color palette (the hex codes) from colorhunt.co.
  4. Section order: always start with Navbar, then Hero, then whatever else (About, Menu, Gallery, Contact...), ending with a Footer. Add a one-line idea for each.

Prompt

  1. Design spec: combine what you like from all your inspiration. Fill in the blanks: 
    Build a single-page, static website for… {WHAT IT’S FOR}

The section and layout are… {YOUR SECTION LIST}

Use these colors and mood… {4 COLOR CODES + A MOOD}

Extract and implement this element in the {SECTION} section {ORIGINKIT LINK}
  2. Enhance: on bolt.new, create an account, paste your prompt, click + then "Enhance prompt". Save the result.

Build

  1. Generate: paste the enhanced prompt into arena.ai (two mystery AIs build side by side; the model names show up after you vote) for two drafts, and stitch.withgoogle.com for two more.
  2. Download the code from your favorite of the 4 drafts (2 from arena + 2 from Stitch).
  3. Open the code in your Claude app (Code tab; needs a paid Claude plan, Pro or up).
  4. Paste this prompt exactly: 
    This is my first time creating a website. Help me polish and finish the website design. I downloaded this from an online tool and would like to work on it locally until we have a final version. Familiarize yourself with the file, open it for me locally so I can see the changes, and let's work section by section from top to bottom, including the elements and anchor links. This is a single page website, static. Guide me through all this process.

Ship

  1. Go live
    • Publish free with GitHub Pages (step-by-step guide). Put your files in a repository (a project folder on GitHub); the main file must be named index.html. Then Settings → Pages → Branch: main → Save. Stuck? Ask Claude: “Help me publish this on GitHub Pages.”
    • Buy a $5 to $12 domain name (e.g. Porkbun, Cloudflare Domains, Squarespace Domains). Check the renewal price too.
    • Connect it to GitHub Pages for free: copy the four numbers from GitHub's guide into your domain's settings (Claude can walk you through it; GitHub guide), then turn on Enforce HTTPS.
Teaching it at home
  • Let the kid pick the topic and the taste: pins, colors, animations.
  • A grown-up owns the accounts (Claude, GitHub, Bolt) and any purchases; kids sit alongside and steer.
  • Keep private info off the site: no home address, school, or phone numbers.
  • Short sessions (about 30 minutes): Collect one day, Build the next.
  • Tip: stuck on any step? Ask Claude: "Explain this step to me like it's my first time."
