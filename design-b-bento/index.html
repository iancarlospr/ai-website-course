Step 10 · The starter prompt /

Say this to Claude, word for word

This first message sets up everything: it tells Claude you are new, what the file is, and how to guide you.

  1. 1Tells Claude you are new
  2. 2Says what the file is
  3. 3Asks it to guide you
Try this

Copy it. Paste it into Claude. Enter.

Starter promptcopy exactly
1This is my first time creating a website. Help me polish and finish the website design. 2I downloaded this from an online tool and would like to work on it locally until we have a final version. Familiarize yourself with the file, open it for me locally so I can see the changes, and let's work section by section from top to bottom, including the elements and anchor links. This is a single page website, static. 3Guide me through all this process.

Read the prompt aloud. Point out what each part does: 'first time' makes Claude explain things simply; 'open it locally' gives you a live preview; 'section by section from top to bottom' keeps it calm and organized; 'including the elements and anchor links' makes sure the menu links scroll to the right sections.

Try this: Copy this prompt, paste it into Claude, and press Enter.

Chloé: Magic words! Not 'abracadabra'. These ones actually work.

Prices vary by name and extension, and renewals can differ from the first-year price, so check both. Connecting the domain means adding a few records; GitHub's guide lists them, and Claude can explain each one. DNS changes can take a little while to kick in.

  • Turn on 'Enforce HTTPS' once it is ready

This is the 'why' slide. Emphasize safety: grown-ups own the accounts and payments, and no personal info goes online. Some tools have age requirements, so the grown-up should be the account holder. Encourage letting kids lead on taste.
