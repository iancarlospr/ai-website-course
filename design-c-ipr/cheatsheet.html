IPR AI Frontend Workflow: Cheat Sheet

From a mood board to a live website in one day. A short course by Ian Ramírez Rivera, Invest Puerto Rico.

Make a folder or note called My Website. Everything you collect goes there.

Collect

  1. Images: search pinterest.com for sites like yours, take a screenshot of each look you like and save 2 or 3 images in your My Website folder. Look for layout, mood and typography.
  2. Animations: save 1 or 2 effect links from originkit.dev and note which section each goes in (for example, Hero).
  3. Colors: copy one 4-color palette (the hex codes) from colorhunt.co. One dark, one light, two accents is an easy mix.
  4. Section order: always start with Navbar, then Hero, then whatever else (About, Services, Gallery, Contact...), ending with a Footer. Add a one-line idea for each.

Prompt

  1. Design spec: combine what you like from all your inspiration. Fill in all five blanks:
    Build a single-page, static website for… {EXPLAIN WEBSITE USE IN YOUR OWN WORDS}

The section and layout are… {INSERT MOCKUP SECTION ORDER AND IDEAS}

Use these colors and mood… {PASTE YOUR 4 COLOR CODES AND A MOOD}

Extract and implement this element in the {DESIRED} section {PASTE LINK FROM OriginKit}

    Two animations? Repeat the last line once for each.

  2. Enhance: on bolt.new, create a free account, paste your prompt, click + then "Enhance prompt". Save the result: that's your master prompt. Then press send and keep the design Bolt builds (draft 1).

Build

  1. Generate: paste the enhanced prompt into
    • arena.ai: choose Side by side in the mode menu, then pick Model A gemini-3.8-flash-high and Model B Claude-sonnet-5-high (drafts 2 and 3)
    • stitch.withgoogle.com: generate a design (draft 4), then ask for a dark version (draft 5):
      Make a second version of this design with a dark theme. Keep the same sections, layout and content, and adjust the colors so the text stays easy to read.
  2. Download the code from your favorite of the 5. Look for Download, Export or Code. Save it in the My Website folder you created earlier.
  3. Open Claude: the Claude desktop app (recommended) or claude.ai in your browser. Click the Code tab and choose the My Website folder.
  4. Paste this prompt exactly:
    This is my first time creating a website. Help me polish and finish the website design. I downloaded this from an online tool and would like to work on it locally until we have a final version. Familiarize yourself with the file, open it for me locally so I can see the changes, and let's work section by section from top to bottom, including the elements and anchor links. This is a single page website, static. Guide me through all this process.

Ship

  1. Go live
    • Publish free with GitHub Pages. Paste this into Claude:
      Publish the website in this folder to GitHub Pages. If I don't have a GitHub account yet, walk me through creating one first. Then create a public repository, upload the files, turn on GitHub Pages and give me the live link.
    • Buy your own domain at Cloudflare or GoDaddy. .com isn't always the cheapest: a fun ending like .site, .xyz, .party or .science can cost less. Check the renewal price too.
    • Ask Claude to connect it (GitHub guide), then turn on Enforce HTTPS:
      Connect my domain yourname.site to my GitHub Pages website. Do it for me if you can, or walk me through each step.

Share it: teach someone

  • Let them pick the topic and the taste: images, colors, animations.
  • You guide the eleven steps, with this sheet next to you.
  • Read Claude's answers together: "Does this look like what we wanted?"
  • Keep personal info off the site: no home address, personal phone, personal email or other personal data.
  • One day works: collect, prompt, build and ship it together.
  • Stuck on any step? Ask Claude: "Explain this step to me like it's my first time."
